## 🤖 Sovereign AI Architecture — What Actually Powers This

### 1. Miracle AI Kernel — 5-Model Sovereign Waterfall
```
Gemini 2.0 Flash → Gemini 1.5 Flash → Gemini 1.5 Flash-8B → Groq LLaMA 3.3 70B → Groq LLaMA 3.1 8B
```
Zero SDK dependency. Pure REST API fallback chain. If one model is rate-limited, the next activates in milliseconds. **No single point of AI failure.**

### 2. Miracle Kernel — The AI Brain of the Entire System
A live JSON knowledge graph (`miracle_kernel.json`) that defines every zone's:
- Natural language knowledge, button labels, navigation commands
- Role-Based Access Control (RBAC) per user tier
- AI persona, greeting context, and operational boundaries
- Business synonyms for zero-hallucination Wisp routing

The **Wisp AI Navigator** reads the kernel in real-time to answer any question about any zone — from guest billing to payroll to procurement.

### 3. Synapse AGI Engine — Fractal Directive Decomposition
A CDO types: *"Prepare the Grand Ballroom for the Al Maktoum family arrival tonight."*

Synapse AGI:
1. Reads the live Neural Tree (org-chart of all active operatives)
2. Detects department scope (Events, HK, F&B, Security)
3. Calls the AI model with context (staff availability, tiers, on-duty status)
4. Returns 12 structured tasks — each assigned to the optimal operative
5. Writes an immutable audit log entry
6. Spawns Z-16 issue tickets for physical verification tasks

### 4. HR AI Intelligence Suite — 5-Engine Workforce Brain
| Engine | What It Does |
|--------|-------------|
| **Churn Radar** | Gemini analyses every employee for flight risk. Scores 0–100. Generates retention strategy per person. |
| **Skill Gap Map** | AI maps department capability gaps. Identifies promotion-ready staff and internal transfer candidates. |
| **Burnout Heatmap** | Analyses working hours and pressure scores. Generates wellness interventions per department. |
| **Operative Copilot** | Staff self-service chatbot. Employee queries their own leave, salary, SOP, policy — answered by Gemini with live DB context. |
| **Compliance Audit** | AI compliance sweep aligned to Bangladesh Labour Act. Checks gratuity eligibility, KYC docs, overtime, terminated payroll. |

### 5. AGI Recruiting Engine (Z-2B)
- **Smart Talent Radar**: Scans every department for urgency score (0–100). Flags understaffed zones automatically.
- **Gemini JD Generator**: Writes full job descriptions (summary, responsibilities, requirements, competencies, benefits) from department data in seconds.
- **GM Approval Queue**: Vacancies need CDO/GM approval before going live — governance baked in.
- **Applicant Pipeline**: NEW → SHORTLISTED → INTERVIEW → OFFER → HIRED. When HIRED, data auto-populates the onboarding form.

### 6. Bot Router V2 — Role-Based AI Persona System
Every user role gets a different AI identity:
- **CDO**: Full sovereign access. Strategic intelligence. No information barrier.
- **GM**: Operations command. Revenue + HR + departments. No financial write access.
- **HR Director**: Full HR intelligence suite, recruiting, payroll visibility.
- **Finance Officer**: Full ledger, P&L, sovereign finance, AGI accounts.
- **Operative**: Zone-restricted. Task-focused. Cannot see cross-department data.
